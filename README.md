# 🎣 悠然垂钓 —— 第一人称钓鱼养鱼游戏

第一人称 3D 视角的休闲钓鱼 & 养成游戏（Three.js 实时水面/天空光照，已内置无需联网加载）。

- **在线游玩**：https://liyucheng1997.github.io/268_game-fishing-fish/
- **本地游玩**：双击 `index.html` 即可，无需安装任何依赖。

## 玩法

### 钓鱼（参照《实况钓鱼 VR》，改为鼠标键盘操作）
1. **抛竿**：按住左键 → 鼠标往下拉（把竿后摆过肩）→ 快速往上甩并松开。甩得越快抛得越远，越远越容易遇到稀有鱼。也可以按住空格蓄力（会显示落点）。
2. **等待咬钩**：能在水下看到鱼游近鱼饵、试探啄饵（浮漂轻点）。轻点左键 = 逗钓诱鱼；按住左键 / R = 收线。
3. **提竿刺鱼**：浮漂被猛地拖入水中时，点击左键或**快速向上甩鼠标**。试探时提竿会把鱼吓跑。
4. **溜鱼**：
   - **按住左键/空格 = 摇轮收线**。
   - **滚轮 = 卸力档位**：张力超过卸力值时渔轮自动出线；张力超过红线会断线。大鱼要调低卸力。
   - 鱼冲刺、卸力正在出线时**别硬摇轮**，否则张力飙升。
   - **鼠标左右 = 侧向压竿**：往鱼游动的**反方向**压，鱼消耗体力更快，还会被扳回头。
   - **鼠标上下 = 竿的高度**：抬竿加压（快速上抬 = 泵竿）；**鱼跃出水面时要压低鱼竿**，否则会被甩钩。
   - 线松太久鱼会脱钩。
5. **提鱼**：鱼没力气后拉到脚下，按住左键或把鼠标移到上方提鱼出水。鱼会被拿在眼前展示，可放入鱼缸、卖出或放生。
6. 按 **H** 随时查看操作说明。

### 养成
- **鱼缸**：养着的鱼会游动展示，按稀有度每分钟产出金币，记得收取；点击鱼可查看详情/卖出/放生。
- **商店**：升级鱼竿（收线更快、安全张力更高）、鱼线（更耐拉不易断）、购买鱼饵（咬钩更快、稀有鱼概率更高）、扩容鱼缸、解锁新钓点。
- **图鉴**：收集全部 23 种鱼，记录最大重量。

### 多样性
- 3 个钓点：宁静池塘（免费）→ 激流河谷 → 碧海深滩，各有专属鱼种。
- 4 档稀有度：普通 / 稀有 / 史诗 / 传说，传说鱼又大又猛，小心断线。
- **昼夜循环**（4 分钟 = 游戏内一天）：部分鱼只在夜晚/白天出没。
- **天气系统**：下雨天咬钩率和稀有率大幅提升。
- 偶尔会钓到破靴子、易拉罐……运气好还有装满金币的宝箱。

存档自动保存在浏览器 localStorage 中。

## 文件结构

```
index.html        页面结构
style.css         界面样式
js/three.min.js   Three.js r147（本地内置）
js/util3d.js      噪声/随机/几何合并/GLSL 片段（焦散等）
js/fishmodel.js   程序化 3D 鱼模型：截面放样鱼身、鳞片/花纹贴图、鳍、眼睛、须，顶点着色器游动
js/sky.js         天空：大气渐变、程序化云层、日月星辰、昼夜/天气参数
js/water.js       水面：平面反射 + 折射 + 深度吸收散射、岸边泡沫、交互涟漪、雨点
js/world.js       三个钓点的地形、远山、树木/芦苇/睡莲、栈桥与道具、灯塔、萤火虫
js/scene3d.js     第一人称渲染：多 pass 调度、鱼竿/渔轮/导环/鱼线/浮漂、鱼、水花、钓获展示
js/fishing.js     钓鱼玩法状态机、溜鱼物理（线长约束/卸力/侧压/跳跃）、HUD
js/aquarium.js    3D 鱼缸（玻璃缸、沙底焦散、水草、气泡、光束）
js/data.js        鱼种/装备/钓点等静态数据（含 3D 外观参数）
js/audio.js       WebAudio 合成音效与环境声
js/state.js       玩家存档与全局状态
js/ui.js          商店/图鉴/弹窗等界面
js/main.js        启动与主循环
dev/              开发工具（无缓存本地服务器 serve.py、鱼模型预览 fishlab.html）
```

调试参数（可组合）：`?demo=1` 注入演示鱼；`?tab=tank` 直达页签；`?pose=waiting|bite|fight|landing|showcase&fish=koi` 进入指定姿态；`?hour=22` 设定游戏时刻；`?freeze=1` 冻结时间；`?wx=rain|cloudy|sunny` 设定天气；`?loc=river` 切换钓点。
