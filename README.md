# 🎣 悠然垂钓 —— 钓鱼养鱼小游戏

一个纯前端（HTML + Canvas + 原生 JS）的休闲钓鱼 & 养成游戏，双击 `index.html` 即可在浏览器中游玩，无需安装任何依赖。

## 玩法

### 钓鱼（核心手感）
1. **抛竿**：按住屏幕（或空格键）蓄力，力度条来回摆动，松开抛竿。抛得越远，越容易钓到稀有鱼。
2. **等待咬钩**：浮漂会有小幅试探（假咬），此时提竿会吓跑鱼；等浮漂**猛地下沉并出现 ❗** 时快速点击提竿。
3. **溜鱼对抗**：
   - **按住 = 收线**，松开 = 放线。
   - 右侧**张力条**进入红区太久会**断线**；线太松太久鱼会**脱钩**。
   - 鱼**冲刺（💨）时一定要松手**，等它消耗体力。
   - 鱼没力气（😮‍💨）后就可以放心快速收线了。
4. 钓到的鱼可以**卖钱**或**放入鱼缸**。

### 养成
- **鱼缸**：养着的鱼会游动展示，按稀有度每分钟产出金币，记得收取；点击鱼可查看详情/卖出/放生。
- **商店**：升级鱼竿（收线更快、安全张力更高）、鱼线（更耐拉不易断）、购买鱼饵（咬钩更快、稀有鱼概率更高）、扩容鱼缸、解锁新钓点。
- **图鉴**：收集全部 23 种鱼，记录最大重量。

### 多样性
- 3 个钓点：宁静池塘（免费）→ 激流河谷 → 碧海深滩，各有专属鱼种。
- 4 档稀有度：普通 / 稀有 / 史诗 / 传说，传说鱼又大又猛，小心断线。
- **昼夜循环**（4 分钟 = 游戏内一天）：部分鱼只在夜晚/白天出没。
- **天气系统**：下雨天咬钩率和稀有率大幅提升。
- 偶尔会钓到破靴子、易拉罐……运气好还有装满金币的宝箱。

存档自动保存在浏览器 localStorage 中。

## 文件结构

```
index.html      页面结构
style.css       界面样式
js/data.js      鱼种/装备/钓点等静态数据
js/audio.js     WebAudio 合成音效
js/state.js     玩家存档与全局状态
js/fishdraw.js  程序化画鱼
js/fishing.js   钓鱼场景（状态机 + 渲染 + 溜鱼手感）
js/aquarium.js  鱼缸场景
js/ui.js        商店/图鉴/弹窗等界面
js/main.js      启动与主循环
```

调试参数：`index.html?demo=1&tab=tank` 可注入演示鱼并直达指定页签（fishing / tank / shop / book）。
